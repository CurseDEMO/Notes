# TeXLive
1. 解压ISO文件
2. 右键以管理员身份运行**install-tl-windows.bat**
![](https://cdn.jsdelivr.net/gh/CurseDEMO/image-bed/image/20260716184631050.png)

# 配置
1. 按下快捷键`Ctrl+,` 打开设置, 点击右上角的**打开设置(json)** 
![](https://cdn.jsdelivr.net/gh/CurseDEMO/image-bed/image/20260716185206452.png)

# 使用
1. 在左边找到TEX图标, 点击
![](https://cdn.jsdelivr.net/gh/CurseDEMO/image-bed/image/20260716191349709.png)
- COMMANDS栏
单击绿色三角形, 即可构建, 生成的PDF在 **查看LaTeX PDF** 下面可以找到. 或者使用`Ctrl+Alt+V` 一键构建查看PDF
2. 你可以在左边第一个像纸一样的图标中, 找到你的PDF文件, 右键点击**在文件资源管理器显示** 打开, 进行保存
![](https://cdn.jsdelivr.net/gh/CurseDEMO/image-bed/image/20260716191919673.png)
