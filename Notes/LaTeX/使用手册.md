# LaTeX基本格式
- 所有命令均以 **\\** 开头, 跟一串字母, 并以任意非字母符号为界限, 如句号, 数字, 标点.
- \\后面也可以跟单个非字母符号.
- 大小写敏感
- 字母形式的LaTeX命令忽略其后的所有连续空格, 若要引入空格, 需要在命令后紧跟 **{}**
```latex
Shall we call ourselves
\TeX users
or \TeX{} users?
```
输出:
Shall we call ourselves TEXusers
or TEX users?
# 基本宏包和文档类
- 规定\[]包裹的是可选参数, \{}包裹的是必选参数
## 文档类
- 规定了文档性质, 如普通文章, 书籍, 演示文稿, 个人简历
- 格式`\documentclass[options]{class-name}` 
- class-name有article, report, book. 除此之外有派生的支持中文排版的ctexart, ctexrep, ctexbook, 还有其他功能的moderncv, beamer
	1. article
	文章格式的文档类，广泛用于科技论文、报告、说明文档等。
	2. report
	长篇报告格式的文档类，具有章节结构，用于综述、长篇论文、简单
	的书籍等。
	3. book
	书籍文档类，包含章节结构和前言、正文、后记等结构。
	4. proc
	基于article 文档类的一个简单的学术文档模板。
	5. slides
	幻灯格式的文档类，使用无衬线字体。
	6. minimal
	一个极其精简的文档类，只设定了纸张大小和基本字号，用作代码测
	试的最小工作示例（Minimal Working Example）。
- options有
	1. 基本字号pt, 默认为10pt
	2. 纸张大小a4paper, letterpaper (默认) , a5paper, b5paper, executivepaper, legalpaper
	3. 排版: 
		1. oneside: 单面, article和report默认值
		2. twoside: 双面, 类似于书本, 奇偶页页边距不同. book默认值
	4. 栏数:
		1. onecolumn: 单栏, 默认
		2. twocolumn: 双栏
	5. 新的一章: 
		1. openright: 指定新的一章始终从奇数页开始, book默认值
		2. openany: 新的一章紧跟上一页, report默认值
		3. 对article无效
	6. landscape: 指定横向排版, 不填则为纵向
	7. 指定标题命令是否单独生成标题页
		1. titlepage: 是, report和book默认值
		2. notitlepage: 否, article默认值
	8. 行间公式左对齐:
		fleqn: 不填表示居中对齐, 默认居中对齐.
	9. 公式编号
		leqno: 公式编号放左边. 不填则在右边, 默认.
	10. 草稿/终端模式:
		1. draft: 草稿模式, 断行不良 (溢出) 的地方会在行尾添加黑色方块
		2. final: 默认值
## 宏包: 一种额外的模组
- 调用`\usepackage[options]{package-name}` 
- {}内的多个宏包调用用 **,** 分隔. 此时不指定options.
# 组织你的文件
- 源代码结构([[../概念解释#扩展名|扩展名]]以.tex结尾)
```LaTeX
\documentclass{...} % ... 为某文档类
% 导言区
\begin{document}
% 正文内容
\end{document}
% 此后内容会被忽略
```
- 显然你需要把一个项目拆成多个文件而非单个文件, 否则维护会变得很苦难.
	- `\include{filename}` 可以插入文件并另起一页, filename如果不在主文件的所在目录, 则需要加上路径(均使用 **/** 分隔)([[../概念解释#相对路径|相对路径]]和[[../概念解释#绝对路径|绝对路径]]).
	- 如果你不想另起一页而是想紧跟上文内容, 则使用`\input{filename}` 
	- 当导言区内容较多时, 通常将导言区另起一个.tex文件
	- `\includeonly{filename1, filename2, ...}`, 用于导言区, 仅加载文件但不导入, 此后正文中的`\include{}` 命令只能导入上述命令规定的文件
# 术语
- **引擎** : 即编译器, 将源代码转化为pdf.
- **格式** : 定义命令的代码集, 如LaTeX就是最广泛的格式
- **编译命令** : 实际调用的结合了引擎和格式的命令, 如xelatex集合了XeTeX引擎和LaTeX格式的编译命令
# 排版文字
- 一般使用ctex及ctex文档类.
- 须将文档保存为UTF-8编码(新手不用管, 默认就是UTF-8)
```latex
\documentclass{ctexart}
\begin{document}
在\LaTeX{}中排版中文。
汉字和English单词混排，通常不需要在中英文之间添加额外的空格。
当然，为了代码的可读性，加上汉字和English 之间的空格也无妨。
汉字换行时不会引入多余的空格。
\end{document}
```

## 空格和分段
- space键和Tab键插入的空白字符均为空格, 连续的空白字符视为一个空格, 一行的开头忽略不计. 行末的单个换行符(即回车)视为空格, 但连续两个换行符, 即空行, 会将文字分段, 多个空行视为一个空行. 效果和在行末使用`\par` 等同
```latex
Several spaces      equal one.
   Front spaces are ignored.


An empty line starts a new
paragraph.\par
A \verb|\par| command does
the same.
```

## 特殊字符
- 有 **\#, \$, \%, \&, \{, \}, \_, \^, \~,  \\** . 想单独显示这些需要在他们前面加上 **\\** (其中显示\^和\~需要这样: `\^{} \~{}` ) , 但显示 **\\** 需要使用`\textbackslash` 
- 英文中 **ff, fi, fl, ffi, ffl** 的字母之间需加上 **{}** 
```latex
It's difficult to find \ldots\\
```

## 手动换行
```latex
\\[length]     % 断行(并增加length的垂直间距), 可用在文本间, 表格公式等.
\\*[length]    % *可以实现禁止在断行处分页
```

# 引入一些元素
## 章节
- 带编号大章节`\chapter{title}`只适用于report和book类. 
- `\section[short title]{title}`通用, 也生成带编号大章节, 启用`short title`后会使得页眉页脚, 目录使用它的内容而不是`title` . 
- 特别的, `\section*{title}` `\chapter*{title}`会使得编号, 目录, 页眉页脚也不生成. 
- `\subsection{title}以及\subsubsection{title}`分别生成小节和小小节. 
- `\paragraph{title}以及\subparagraph{title}`不带编号
- 各个文档类带编号层级(从左到右降序)
	- **article**: \section \subsection \subsubsection
	- **book和report**: \chapter \section \subsection
## 目录
- `\tableofcontents` 生成章和节
- 若使用了不带编号的章节命令, 但又想添加到目录, 则在章节命令后面跟上`\addcontentsline{toc}{level}{title}`, 其中toc这个单词不得更改, level为章节层级chapter, section等, title为标题
## 附录, 前言, 正文, 后记
- 附录`\appendix`
- 前言`\frontmatter`
- 正文`\mainmatter`
- 后记\backmatter`
## 标题页
```latex
\title{title} % 标题, 必须
\author{author1\thanks{content} \and author2\thanks{content} \and author3} % 作者, 必须. \and分隔多个作者, \thanks{content}, 生成脚注.
\date{date} % 生成日期, 若date用\today代替则\生成当天日期, 可选.

...


% 随后用以下命令生成标题页
\maketitle
```

## 交叉引用
- `\label{label-name}`生成一个引用, 随后使用`\ref{label-name}`或`\pageref{label-name}`分别生成编号和页码.
- 交叉引用可以用在很多地方, 如:
	- 章节标题: `\section`后面立即使用, 但不要在`\section*`后面使用
	- 行间公式: 单行公式内任意位置使用, 多行公式内每一行公式内任意位置使用
	- 有序列表: enumerate环境内每一个`\item`之后, 下一个`\item` 前使用.
	- 图表标题: `\caption`之后立即使用, 但不要在`\caption*`后面使用
	- 定理环境: 内部任意使用
- ==有些看不懂, 后面就懂了==
## 脚注和边注
- `\footnote{footnote}`生成脚注.
	- 如果在某些情况下, 无法生成正确的脚注. 则需要分两步进行:
```latex
1 + 1 = 2 \footnotemark


...
\footnotetext{footnotemark} % 与前文的\footnotemark配对
```
- `\marginpar[left-margin]{right-margin}` 若不指定left-margin, 则奇偶页均使用right-margin. 否则奇数页使用right-margin, 偶数页使用left-margin.
## 列表
```latex
\begin{enumerate} % 列表环境enumerate开始
	\item An item. % 第一项
	\begin{enumerate} % 嵌套列表环境enumerate开始
		\item A nested item.\label{itref} % 嵌套第一项, 并赋予交叉引用itref
		\item[*] A starred item. % 嵌套第二项, 将符号替换为*
	\end{enumerate} % 嵌套列表环境enumerate结束
	\item Reference(\ref{itref}). % 第二项, 生成交叉引用itref
\end{enumerate} % 列表环境enumerate结束
```
